# Contributing

Thanks for your interest in contributing to mu-multi-agent!

## How to contribute

- **Bug reports & feature requests**: open an issue using the provided templates.
- **Pull requests**: fork the repo, create a branch, and submit a PR with a clear description of what changed and why.

## Guidelines

- This project is a methodology skill — `SKILL.md` is the single source of truth. Keep it self-contained and dependency-free.
- Keep the writing style consistent: plain language, concrete examples, no marketing fluff.
- Test your changes by loading the skill in an agent that supports the Skill / SKILL.md convention and running a real multi-agent task.
- By contributing, you agree that your contributions will be licensed under the MIT License.
